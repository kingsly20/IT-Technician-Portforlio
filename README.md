# IT Support Portfolio

Hands-on projects covering Windows and Linux administration, encryption, and Active Directory. Built while studying for CompTIA A+, Network+, and Security+, and while completing coursework in operating systems, Linux security, and Windows security strategies.

## Projects

**[File Encryption Automation: EFS and BitLocker](./encryption-efs-bitlocker/)**
PowerShell scripts that automate EFS encryption and decryption through `cipher.exe`, plus a guide to when EFS beats BitLocker and when it doesn't.

**[Cross-Platform Backup and Recovery](./backup-recovery/)**
A Bash toolkit for backing up, restoring, and recovering deleted files on Linux, including a method for pulling back a deleted file through its process ID. Includes a comparison to the equivalent Windows tools.

**[Active Directory User and Permissions Provisioning](./windows-active-directory/)**
A PowerShell script that provisions AD users and groups, creates their shared folders, and applies NTFS permissions, all from a single CSV.
